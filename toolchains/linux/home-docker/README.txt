Welcome to Opcode Docker: a Linux computer with Docker, in your browser.

Things to try:
  tutorial                     a guided, hands-on introduction to Docker
  docker run hello-world       run your first container
  docker run -it alpine sh     a shell inside a container (exit leaves)
  docker images                the images on this machine
  docker ps -a                 the containers, running or not

Examples to build and run:
  hello-web/      a web page served by nginx (a Dockerfile)
  compose-demo/   two containers started together (docker compose up)

Docker here runs 32-bit (linux/386) images. hello-world, alpine, busybox
and nginx:alpine-slim are already here; go online to pull others.

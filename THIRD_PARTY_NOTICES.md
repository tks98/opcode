# Third-party software

Opcode itself is licensed under the GNU Affero General Public License, version 3 or later (see `LICENSE`). It is built on, and serves, a lot of other open source software, each under its own license. This file lists it and where its source code is.

A production build also contains `third-party-licenses.txt`, with the full license texts of the npm packages bundled into the app or copied into it (generated by `vite.config.js`). The start screen links to it.

## Toolchains

The compilers and interpreters Opcode serves from `public/toolchains/`, committed or prepared by `npm run build`:

| Toolchain | License | Source |
| --- | --- | --- |
| Go: Yaegi, with the Go standard library (`toolchains/go`) | Apache-2.0; Go: BSD-3-Clause | https://github.com/traefik/yaegi, https://go.dev |
| SQLite (`toolchains/sqlite`) | Public domain | https://www.sqlite.org |
| Lua (`toolchains/lua`) | MIT (notice below) | https://www.lua.org |
| Rust: rustc and the standard library, built for WebAssembly by rust_wasm (`scripts/fetch-rust.mjs`) | MIT OR Apache-2.0; LLVM: Apache-2.0 WITH LLVM-exception | https://github.com/oligamiq/rust_wasm, https://github.com/rust-lang/rust |
| Java: Ristretto, teavm-javac (OpenJDK's javac) and Amazon Corretto 21's class library (`toolchains/java`) | Ristretto: Apache-2.0 OR MIT; TeaVM: Apache-2.0; javac and Corretto: GPL-2.0 WITH Classpath-exception-2.0 | See `toolchains/java/README.md` |
| C#: .NET 8 runtime and libraries, Roslyn (`toolchains/csharp`) | MIT | https://github.com/dotnet/runtime, https://github.com/dotnet/roslyn |
| Ruby 3.2, WASI build by VMware Labs (`@antonz/ruby-wasi`) | Ruby: BSD-2-Clause (or the Ruby license); build: Apache-2.0 | https://github.com/ruby/ruby, https://github.com/vmware-labs/webassembly-language-runtimes |
| TypeScript, with Node.js type definitions (`@types/node`, `undici-types`) | Apache-2.0; type definitions: MIT | https://github.com/microsoft/TypeScript, https://github.com/DefinitelyTyped/DefinitelyTyped |

`stty` and `opcode-wait` (`toolchains/stty`, `toolchains/opcode-wait`) are Opcode's own code, built against wasi-libc (Apache-2.0 WITH LLVM-exception, Apache-2.0 or MIT; https://github.com/WebAssembly/wasi-libc).

## Linux and Docker machines

The machine snapshots in `public/linux/` and `public/linux-docker/` contain Alpine Linux, the Linux kernel, GNU tools, Docker Engine and container images, under licenses including the GPL. Their `README.md` files list them and where their source code is, and `toolchains/linux/` shows how they are built.

## Downloaded from Wasmer, not served by Opcode

Browsers download these directly from the Wasmer registry (https://wasmer.io) when they are first used; they are under their own licenses: the terminal's tools (bash, coreutils and others), Python, Node.js (Edge.js), PHP and static-web-server. By default the web preview also runs through Wasmer's preview host.
